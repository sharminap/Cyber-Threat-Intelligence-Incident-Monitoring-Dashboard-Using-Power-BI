# Cybersecurity Threat Analysis Dashboard

## 📌 Project Overview

The Cybersecurity Threat Analysis Dashboard is an interactive Power BI project designed to analyze cybersecurity incidents, identify attack trends, and support data-driven security monitoring. The project focuses on transforming raw security data into meaningful insights through data cleaning, preprocessing, and visualization.

This dashboard enables users to monitor threat categories, attack frequency, incident severity, and overall security trends using dynamic and interactive reports.

---

## 🚀 Features

- Interactive Power BI dashboard
- Data cleaning and transformation using Power Query
- KPI cards for key cybersecurity metrics
- Threat category analysis
- Incident trend visualization
- Dynamic filtering using slicers
- User-friendly dashboard for security monitoring

---

## 🛠️ Tech Stack

- Power BI
- Power Query
- Microsoft Excel
- Data Visualization

---

## 📊 Dataset

The project uses a cybersecurity incident dataset containing information such as:

- Incident ID
- Threat Type
- Severity Level
- Attack Category
- Date & Time
- Affected System
- Status

---

## 🔄 Data Processing Workflow

1. Imported the raw dataset into Power BI.
2. Cleaned missing and inconsistent data using Power Query.
3. Transformed and standardized data for accurate analysis.
4. Created calculated columns and KPIs.
5. Built interactive visualizations and dashboards.
6. Published insights for reporting and decision-making.

---

## 📈 Dashboard Insights

The dashboard provides insights into:

- Total security incidents
- Threat distribution by category
- Incident severity analysis
- Monthly attack trends
- High-risk threat identification
- Security status overview
